# 💬 Full-Stack Chat Suite (yuliskov)
> **MyChatClient + MyChatService + MyAuthService**
- **Repos:** `yuliskov/MyChatClient`, `yuliskov/MyChatService`, `yuliskov/MyAuthService`
- **Tech Stack:** Kotlin, Jetpack Compose, WebSockets, Spring Security, JWT
- **Key Features:**
  - Real-time bi-directional messaging with WebSockets.
  - Token-based authentication using JWT and OAuth2 social login.
  - Modern declarative UI built with Jetpack Compose.
