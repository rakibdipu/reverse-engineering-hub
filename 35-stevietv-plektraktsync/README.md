## 🚀 How We Made It Better / What Was Merged
- Two-way synchronization algorithm between local Plex Media Server and cloud Trakt.tv.\n- Syncs ratings, watch progress percentages, and watch history.\n- Runs completely locally without requiring costly PlexPass or Trakt VIP.
