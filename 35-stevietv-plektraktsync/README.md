# 🔄 PlexTraktSync (stevietv)
> **Bidirectional Sync between Local Plex Server and Trakt.tv**
- **Repo:** [stevietv/PlexTraktSync](https://github.com/stevietv/PlexTraktSync)
- **Tech Stack:** Python, Plex API, Trakt API
- **Key Features:**
  - Syncs watched history, ratings, and playback progress between Plex and Trakt.tv.
  - Works without PlexPass or Trakt VIP subscription.
