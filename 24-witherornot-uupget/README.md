## 🚀 How We Made It Better / What Was Merged
- Direct query client for Microsoft Unified Update Platform (UUP) catalog endpoints.\n- Extracts official ESD and CAB download URLs with cryptographic SHA1/SHA256 checksums.\n- Zero third-party mirror reliance — connects directly to official Windows Update CDNs.
