# ⬇️ uupget (WitherOrNot)
> **Python Implementation of Microsoft Windows Update UUP API**
- **Repo:** [WitherOrNot/uupget](https://github.com/WitherOrNot/uupget)
- **Tech Stack:** Python, HTTP, REST
- **Key Features:**
  - Direct communication with Microsoft Update Servers (Unified Update Platform).
  - Fetches original ESD/CAB update packages without third-party mirrors.
