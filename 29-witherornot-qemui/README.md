## 🚀 How We Made It Better / What Was Merged
- Python CLI runner and profile generator for QEMU virtualization.\n- Automatically configures KVM/WHPX hardware acceleration, bridge networking, and UEFI firmware.\n- Lightweight alternative to bloated virtualization managers.
