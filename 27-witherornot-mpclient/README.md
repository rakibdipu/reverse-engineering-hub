# 🛡️ mpclient (WitherOrNot)
> **Standalone Native C Client for Microsoft Defender mpengine.dll**
- **Repo:** [WitherOrNot/mpclient](https://github.com/WitherOrNot/mpclient)
- **Tech Stack:** C, Win32 Internals
- **Key Features:**
  - Directly loads Microsoft Defender core engine (`mpengine.dll`).
  - Scans files from the command line without GUI or Windows Security service overhead.
