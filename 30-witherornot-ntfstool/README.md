## 🚀 How We Made It Better / What Was Merged
- Direct binary parser for Master File Table ($MFT) records in NTFS volumes.\n- Extracts standard information and file name attributes ($STANDARD_INFORMATION, $FILE_NAME).\n- Enables forensic file recovery and BitLocker partition inspection.
