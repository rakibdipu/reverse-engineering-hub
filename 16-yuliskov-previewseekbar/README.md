# 🎞️ PreviewSeekBar (yuliskov)
> **Thumbnail Preview Scrub Bar for Android Video Players**
- **Repo:** [yuliskov/PreviewSeekBar](https://github.com/yuliskov/PreviewSeekBar)
- **Tech Stack:** Java, Android Views
- **Key Features:**
  - Shows floating video frame thumbnail as the user scrubs forward/backward.
  - Smooth animation, caching, and low memory usage.
