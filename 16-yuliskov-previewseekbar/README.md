## 🚀 How We Made It Better / What Was Merged
- Engine for WebVTT/Storyboard thumbnail sheet parsing.\n- Maps playback seconds directly into sprite coordinates (X, Y, W, H) for instant scrubbing.\n- Can be integrated into any web, Qt, or desktop media player.
