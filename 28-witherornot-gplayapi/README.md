# 📱 gplayapi (WitherOrNot)
> **Headless Python Client for Google Play Store API**
- **Repo:** [WitherOrNot/gplayapi](https://github.com/WitherOrNot/gplayapi)
- **Tech Stack:** Python, Protobuf, HTTPS
- **Key Features:**
  - Authenticates and fetches APKs, split APKs (APKs bundle), and app metadata directly from Google servers.
